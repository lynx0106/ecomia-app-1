## 💡 Tips Pro

### Tip 1: Buscar un Archivo Específico

En GitHub, presiona `/` (slash) y escribe el nombre del archivo:
```
Presiona: /
Escribe: BUGS_RESUELTOS
Enter
```

### Tip 2: Índice del README

El archivo `README.md` tiene un índice con links a todos los documentos.

1. Abre README.md
2. Busca la sección "Documentación"
3. Cada bullet tiene un link directo

### Tip 3: Ctrl+F Para Buscar

Dentro de cualquier archivo abierto:
```
Windows/Linux: Ctrl + F
Mac: Cmd + F
```

Busca palabras clave como:
- "bug"
- "error"
- "onboarding"
- "chat"
- "Vercel"

### Tip 4: Ver Historial

Para ver cuándo se creó/modificó un archivo:
1. Abre el archivo en GitHub
2. Click en "History" (arriba a la derecha)
3. Ve todos los cambios

## ❓ Preguntas Frecuentes

### ¿Puedo editar los archivos?

**Desde GitHub Web:** No directamente (necesitas permisos)  
**Desde un Codespace:** Sí, pero no es necesario  
**Recomendación:** Solo léelos, no necesitas editarlos

### ¿Los archivos cambian?

Sí, se actualizan cuando hay nuevos cambios. Pero los links siguen siendo los mismos.

### ¿Puedo descargar un archivo?

**Sí:**
1. Abre el archivo en GitHub
2. Click en "Raw" (arriba a la derecha)
3. Click derecho → Guardar como

O descarga todo el repositorio:
- Click en "Code" → "Download ZIP"

### ¿Puedo compartir un link?

**Sí, absolutamente:**
- Copia el URL cuando abres un archivo
- Compártelo con quien quieras
- Ejemplo: https://github.com/lynx0106/ecomia-app-1/blob/main/README.md

### ¿Necesito cuenta de GitHub?

**Para ver:** No, son públicos  
**Para editar:** Sí, necesitas cuenta y permisos
