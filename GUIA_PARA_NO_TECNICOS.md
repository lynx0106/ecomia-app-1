## 📝 Plantillas de Preguntas Útiles

### Para Hacer Cambios:

- "Quiero que [descripción del cambio]"
- "¿Podrías cambiar [X] a [Y]?"
- "Necesito agregar [función/característica]"
- "Quiero que se vea como [descripción]"

### Para Probar:

- "¿Funciona todo bien?"
- "Prueba si [X] está funcionando"
- "¿Hay errores?"
- "Verifica que [X] funcione"

### Para Corregir:

- "Eso no funcionó, ¿puedes arreglarlo?"
- "Hay un error cuando [descripción]"
- "Eso no es lo que quería, mejor [descripción]"
- "Regresa al anterior, este no me gustó"

### Para Entender:

- "¿Qué hace [esto]?"
- "Explícame [X] en palabras simples"
- "¿Por qué [sucede algo]?"
- "¿Cómo funciona [X]?"
