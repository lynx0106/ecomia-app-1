# 📋 Templates de Reporte - Uso Rápido

## Template Básico (Copia y Pega)

```
🐛 PROBLEMA:

¿Qué pasó?
[Describe el problema]

¿En qué página?
[URL]

¿Dispositivo?
[Computadora/Celular/Tablet]

¿Más detalles?
[Cualquier otra información]
```

---

## Template Detallado

```
🐛 REPORTE DE PROBLEMA

📍 Ubicación:
   URL: [URL completa]
   Sección: [Nombre de la página/sección]

🎯 Acción Realizada:
   [Qué estabas haciendo cuando pasó]

❌ Qué Pasó:
   [Descripción del problema]

✅ Qué Esperabas:
   [Qué debería haber pasado]

💻 Dispositivo:
   - Tipo: [Computadora/Tablet/Celular]
   - Navegador: [Chrome/Firefox/Safari/Edge]
   - Sistema: [Windows/Mac/iOS/Android]

🔴 Prioridad:
   [Crítico 🔴 / Importante 🟡 / Menor 🟢]

📸 Captura:
   [Sí/No - describe si tienes]
```

## Checklist Antes de Reportar

Antes de enviar tu reporte, verifica:

- [ ] Incluí la URL completa
- [ ] Describí qué estaba haciendo
- [ ] Describí qué pasó
- [ ] Mencioné el dispositivo
- [ ] Agregué detalles útiles

---

## Reportes Ultra Rápidos (1 Línea)

Si tienes prisa, puedes reportar así:

```
"Botón X no funciona en página Y"
"Error al cargar Z"
"Texto cortado en W"
"La página V tarda mucho"
```

Y yo te preguntaré más detalles si los necesito.

---

## Categorías de Problemas

### 🐛 Bugs (Errores)
Algo que no funciona como debería

### 💡 Mejoras (Sugerencias)
Ideas para hacer algo mejor

### ❓ Dudas (Preguntas)
No entiendes cómo funciona algo

### 📝 Typos (Errores de texto)
Errores ortográficos o de redacción

### 🎨 Visual (Diseño)
Problemas con cómo se ve algo

### ⚡ Performance (Velocidad)
Algo es lento o tarda mucho

---

## Respuestas Típicas

Después de reportar, yo podría responderte:

### "Entendido, lo reviso"
Recibí tu reporte y lo estoy investigando

### "¿Podrías darme más detalles sobre X?"
Necesito información adicional

### "Ya lo arreglé, verifica por favor"
El problema está resuelto, confirma

### "Eso es normal porque..."
Te explico por qué funciona así

### "Excelente sugerencia, lo implemento"
Me gusta tu idea y la voy a hacer

---

## Tips de Oro

### ✅ Buenos Reportes:
- Son específicos
- Incluyen la URL
- Mencionan el dispositivo
- Son claros y concisos

### ❌ Reportes Difíciles:
- "No funciona"
- "Está roto"
- "Hay un error"
- Sin más detalles

---

## Flujo Ideal

```
1. TÚ: Encuentras problema
2. TÚ: Me lo reportas (usa template)
3. YO: Lo recibo y confirmo
4. YO: Lo investigo (5-30 min)
5. YO: Lo arreglo
6. YO: Te aviso que está listo
7. TÚ: Verificas que funcione
8. AMBOS: ✅ Cerrado
```

## Ejemplo de Conversación

**Tú:**
```
🐛 PROBLEMA:

¿Qué pasó?
No puedo iniciar sesión, dice "error de conexión"

¿En qué página?
https://ecom-ia.online/login

¿Dispositivo?
Computadora, Chrome
```

**Yo:**
```
Entendido, reviso la conexión con Supabase.
¿Te pasa con cualquier email/password o solo con uno específico?
```

**Tú:**
```
Con cualquiera, he probado 3 cuentas diferentes
```

**Yo:**
```
Encontré el problema, era un issue con las variables de entorno.
Ya está arreglado. ¿Puedes probar de nuevo?
```

**Tú:**
```
Sí, ya funciona! Gracias
```

**Yo:**
```
Perfecto! Marcado como resuelto ✅
```

## Herramientas Útiles

### Tomar Captura de Pantalla:
- **Windows:** Win + Shift + S
- **Mac:** Cmd + Shift + 4
- **iPhone:** Botón lateral + Volumen arriba
- **Android:** Botón encendido + Volumen abajo

### Ver Console del Navegador:
- **Todos:** F12 o Clic derecho → "Inspeccionar"
- Ve a pestaña "Console"
- Copia errores en rojo si los hay
